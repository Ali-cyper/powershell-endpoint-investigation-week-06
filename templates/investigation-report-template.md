# Investigation Report Template

```
CASE ID:
INITIAL ALERT (rule + host + user + time):
TIMELINE (own words):
ONE-SENTENCE STORY (explains all evidence):
PROCESS TREE (with arrows):
DECODED COMMAND:
PERSISTENCE (type / name / command / creator / independent mechanisms):
NETWORK:
WHAT I KNOW:
WHAT I ASSUME (and what would prove it):
STRONGEST EVIDENCE (and why):
WEAKEST EVIDENCE (and why):
MISSING EVIDENCE (what I do not have):
WHAT WOULD CHANGE MY MIND (opposite to my verdict, verifiable):
VERDICT: TP / FP / UNDETERMINED
CONFIDENCE (low/med/high) + IMPACT:
RECOMMENDED RESPONSE (including scoping):
ENGLISH VERDICT (3-5 sentences, starts with the decision):
```

**Sentence starters:** `I assess this as a true positive / false positive because ...` · `The task runs every ... minutes and tries to contact ...` · `I could not confirm ... because ... is missing.` · `I would isolate the host and review ... before closing.`
